# Provenance

This skill is an independent orchestration layer for the official Excalidraw MCP App, editable local Excalidraw diagrams, deterministic browser rendering, and recovery of interactive canvas state. The MCP service is referenced as an optional dependency and is not copied into this repository.

The licensing review was prompted by [`coleam00/excalidraw-diagram-skill`](https://github.com/coleam00/excalidraw-diagram-skill). That repository did not include a license file when this implementation was prepared, so its files are not included here. The skill instructions, renderer, tests, and recovery guide in this repository were written separately for this project.

Private diagrams, local session logs, machine-specific paths, checkpoint values, and diagram-specific recovery scripts are intentionally excluded.
